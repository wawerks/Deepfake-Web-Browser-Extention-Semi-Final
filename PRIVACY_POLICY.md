# 📄 PRIVACY POLICY

**Last Updated: December 2025**

## 1. Introduction

This Privacy Policy explains how this browser extension ("the Extension") collects, processes, and handles information when you analyze images for authenticity. The Extension is designed to detect AI-generated and manipulated images in real time using a third-party analysis service.

By installing or using the Extension, you acknowledge and agree to the practices described in this policy.

## 2. Information We Collect

The Extension does not collect personal information such as names, email addresses, browsing history, cookies, logins, or device identifiers.

The only data that may be transmitted is:

- Image data (image URL or image file bytes)
- Automatically generated API response results
- Confidence scores returned by the detection API

No other data collection occurs.

## 3. How Image Data Is Used

When you trigger a detection action (via right-click, click analysis, or upload interception), the Extension sends image data to a secure backend server, which forwards it to the Sightengine AI Detection API for analysis.

**Important Data Handling Principles:**

- Images are processed only on demand, never automatically.
- Images are not stored, logged, or retained after analysis.
- Image data is transmitted temporarily and only for the duration of the analysis request.
- Your images are not used to train AI systems, build datasets, or create user profiles.

## 4. Third-Party API Disclosure

The image analysis is performed by **Sightengine** (https://sightengine.com/).

As part of using this Extension:

- Image bytes or URLs may be transmitted to Sightengine servers for classification.
- Sightengine applies its own privacy and data handling policies.
- We do not control Sightengine's internal operations, storage practices, or model behavior.

By using the Extension, you consent to the transmission of images to a third-party provider solely for authenticity detection.

## 5. Security Measures

We follow secure design principles and responsible AI usage practices:

- HTTPS encrypted communication for all analysis requests
- No local storage of images
- No cloud database logging
- No sharing of collected data with third parties other than Sightengine
- Data minimization and transient processing

## 6. Children's Privacy

This Extension is not intended for use by minors under 13 years of age. No personal data is knowingly collected from children.

## 7. Legal Compliance

We follow applicable data protection principles, including:

- Philippines Data Privacy Act (RA 10173)
- EU Artificial Intelligence Act (2024) transparency guidelines
- Responsible AI and data minimization practices

## 8. Your Rights

Since no personally identifiable information is stored, typical user data rights (access, correction, deletion) are not applicable.

However, you may always:

- Uninstall or disable the Extension
- Stop using detection features at any time

## 9. Changes to This Policy

We may modify this Privacy Policy to reflect updates in the system, third-party providers, or regulatory requirements. The "Last Updated" date will be revised accordingly.

## 10. Contact

For questions regarding this policy, contact the developers of this research project.
