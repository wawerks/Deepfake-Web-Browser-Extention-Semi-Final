# Third-Party API Usage Policy

**Last Updated: December 2025**

## Overview

AI Image Guard uses **Sightengine** (https://sightengine.com/) as a third-party API service for image authenticity detection. This policy outlines the regulations and guidelines regarding third-party API usage.

## Third-Party Service: Sightengine

### Service Provider

- **Name**: Sightengine
- **Website**: https://sightengine.com/
- **Purpose**: AI-powered image authenticity detection and classification
- **Service Type**: Cloud-based API service

### How Sightengine Is Used

When you use the Extension to detect images:

1. **Image Transmission**: Image data (URLs or file bytes) is sent to your configured backend server
2. **Server Processing**: Your backend server forwards the image to Sightengine's API
3. **Analysis**: Sightengine analyzes the image and returns detection results
4. **Results Display**: Results are displayed in the Extension interface

### Data Transmission

**What is sent to Sightengine:**
- Image URLs or image file bytes
- API request metadata (for service operation)

**What is NOT sent:**
- Personal information (names, emails, etc.)
- Browsing history
- Device identifiers
- Login credentials
