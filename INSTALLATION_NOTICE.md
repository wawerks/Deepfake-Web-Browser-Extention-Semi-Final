# Installation Notice & Important Information

**AI Image Guard Browser Extension**

## Important: Third-Party API Usage Policy

Before installing or using this extension, please read and understand the following:

### Third-Party Service: Sightengine

This extension uses **Sightengine** (https://sightengine.com/) for image authenticity detection.

**What this means:**
- Image data (URLs or file bytes) is sent to Sightengine servers for analysis
- Sightengine applies its own privacy and data handling policies
- We do not control Sightengine's internal operations or data retention
- By using this Extension, you consent to image transmission to Sightengine

### Your Consent

By installing and using this Extension, you acknowledge that:

1. Images you analyze may be transmitted to Sightengine servers
2. Sightengine's privacy policy and terms of service apply to your image data
3. You have reviewed and understand this policy
4. You consent to third-party processing for authenticity detection

### Quick Summary

✅ **What the Extension Does:**
- Sends image data to Sightengine for authenticity detection
- Displays detection results (confidence scores)
- Does not store images locally
- Does not collect personal information

⚠️ **What You Must Understand:**
- Images are transmitted to Sightengine servers
- Sightengine's privacy policies apply to your image data
- Detection results are probabilistic and may contain errors
- Do not use for harassment, surveillance, or harmful purposes

### Installation

1. **Load Unpacked Extension**:
   - Open Chrome → `chrome://extensions`
   - Enable "Developer mode"
   - Click "Load unpacked"
   - Select this extension folder

2. **Configure Your Server**:
   - Click the extension icon
   - Go to Settings/Options
   - Enter your detection server URL (which uses Sightengine API)
   - Test the connection

3. **Review Policies**:
   - Read the Privacy Policy
   - Read the Terms of Use
   - Read the Third-Party API Policy
   - Review Sightengine's policies at https://sightengine.com/
